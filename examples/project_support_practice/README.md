# Optional Reading examples | Weeks 12–14

Run these examples to follow the Readings. They do not run the robot simulation and are not part of the project submission. The Reading ZIP contains the same scripts and JSON inputs.

Open Anaconda Prompt **in this folder** and activate the existing course environment:

```bat
conda activate applied-programming-cuda
```

| Week | Run one example | What to look for |
| --- | --- | --- |
| 12 | `python batch_records.py` | Compare settings A and B on the same two cases. Each run appends four records to `demo_runs.jsonl` in this folder, including the failed case. |
| 13 | `python model_example.py` | Compare predicted and reference times using the features and weights in `model_example.json`. |
| 14 | `python result_meaning.py` | Read the two supplied CPU result excerpts. A successful plan is not evidence of physical transport. |

Keep the supplied JSON files beside the Python files. No additional installation or student edits are required.
